☁ Shared job database
The local database is yours alone. The shared one puts every folder pin, Trello link and alias in one place so the whole office sees the same job, from any machine. You still only see the franchises you belong to — the database enforces that, not the app.

🔗 Job identity
Look up what's tied to a job — its canonical name, the alternate spellings that resolve to it, and its folder / Trello / CompanyCam links. Auto-linking learns these as you pin folders and cards. "Backfill" seeds the graph from every folder + Trello pin you've already made.
📌 Sidebar visibility
Hide panels you don't open often. The backend stays wired — data still flows into audit / snapshot / hygiene popovers etc. Job Notes is hidden by default since its timeline already shows in the 🗒 hover popover on audit + snapshot rows.
🏢 Franchises
One franchise is the default — leave this off and everything below is simply your office. Turn it on to run the tools against several, each with its own Trello board, job/photo folders, CompanyCam account and office identity, and a switcher appears at the top of the launcher.

Give each franchise its own Trello workspace, folder roots and CompanyCam token. A field left blank inherits the base, and a base edit can then silently point that franchise at another one's data — which is how OC's CompanyCam projects were being created in IE's account. Appearance and feature flags stay shared.
🌐 Per-franchise browser
Open Trello / XactAnalysis / CompanyCam links in a different browser per franchise, so each one's logins stay separate. Point each side at a browser .exe (e.g. two Helium installs), or a command with {url} for a profile, e.g. helium.exe --profile-directory=OC {url}. Blank = system default.
