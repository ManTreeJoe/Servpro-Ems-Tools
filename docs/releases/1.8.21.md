# Linguar Hub 1.8.21

Windows Main update. Upgrades the existing installation while retaining each user's settings and job data.

## Included

- Job cards display saved information first. Background refresh patches changed sections without replacing the entire card or discarding comments, checklist edits, selected tabs or expanded evidence. Saved documents remain visible during loading; folder audits run on request.
- Job-card and form backdrops no longer dismiss the popup on an outside click/release. Explicit Close/Cancel and draft protection remain.
- Comments remain available on the right, with one linked division selected at a time and an explicit posting destination. Trello attachment import and initial-checklist automatic comments are available again.
- Shared New Loss entry from Operations, EMS Residential template default, saved customer/job facts and CompanyCam-to-Trello link handling. Signed-in CompanyCam requests prefer the user's connected account. Existing provider connections are still required.
- Saved folder and CompanyCam destinations resolve by exact card. Snapshot and Quick Import forward the same exact-card arguments.
- APA paste review processes complete table rows one at a time: review the Trello match, add a pending entry, confirm an existing entry or skip. Initial/Final and Contents remain distinct. Contents initials route to Initial Uploads/AARON; Contents finals to PABLO. Existing rows are not silently moved or reclassified.
- APA lane/drop fixes and local before/after document recovery copies.
- Weekly Logs audit queue, source-backed field suggestions, saved findings, AR evidence comparison, explicit preview/confirmation for Trello comments and moves, and a filled weekly Excel copy. Audited and explicitly billed jobs can be filed; payment is not required. Changed evidence requires a fresh review rather than a blind retry.

## Boundaries

- Weekly review drafts, queues, history and APA recovery copies remain local to each PC. They are not a new shared database or an off-device backup.
- APA Word documents remain the live document source; digital-first database migration is not part of this update.
- Unknown evidence remains unknown and needs review. WC/file status is manual; billing completion requires explicit billing/sent-to-payer evidence, not merely an invoice or payment mention.
- No database migrations, QuickBooks integration, estimator auto-assignment/dispute carryover, or completed app-wide overhaul is included.
- Publishing this installer does not perform a bulk Trello audit or move customer cards. Those actions remain explicit in-app confirmations.
- The previous 1.8.20 installer remains available on GitHub for rollback. Installation is offered through the existing update flow; it is not a forced deployment to every PC.

## Verification

Release audit and automated test/build results are recorded in `docs/approved-hub-overhaul-20260918.md`. UI regressions exercise production renderers with mocked APIs; they do not certify live provider writes. The current dev interface was reviewed and approved by the user before packaging.
