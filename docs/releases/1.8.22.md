# Linguar Hub 1.8.22 — release candidate

Publication status: verified candidate; publication handoff in progress.

## Included in the candidate

- Independent saved Job Log records, explicit Trello import, deletion/dismissal protection and printable logs.
- App-owned card location, archive/delete flow, ordered drag-and-drop and APA status feedback.
- Linked EMS/Contents/Recon workspace tabs, explicit multi-division posting, rich comment formatting and board-scoped @mentions.
- Background preload of verified linked divisions without speculative Job Log refreshes.
- Local draft recovery and transactional offline-write recovery.
- CompanyCam visit review, folder handling and local import receipts.
- Schedule job navigation, file/photo viewing and quieter loading/error feedback.

## Boundaries

- Stages loading latency remains under investigation; this release does not claim to resolve it.
- Shared historical Run Activity needs reviewed exact-job links. CompanyCam receipts and recovery drafts remain local; they are not cross-PC backups.
- Publishing the desktop installer does not apply database migrations or deploy provider functions.
- Existing provider connections and shared database permissions remain required.
- Automated fixtures do not certify every live integration or cross-PC race.

## Verification

### Regression cleanup

The diagnosis skill guided isolated versus suite reproduction. The partial-schema failure passed alone and failed after the missing-schema test: its cached absence results were leaking across independently mocked databases. The queue test module now isolates that cache without weakening partial-schema, authentication or timeout assertions. Saved-board fallback tests isolate the newer server-mirror and placement decorator dependencies. The lane-move test now exercises the app-owned versioned placement interface, still forbidding an interactive Trello move.

The former unsupported-dismissal assertion predated persistent dismissal events. Its replacement verifies an acknowledged event hides the dismissed entry on reread, preserves the source comment identifier and sibling entry, and propagates event-save failure. Theme and drag assertions now follow the shared neutral palette and actual shelf bounds. No production behavior was changed in this cleanup.

Focused rerun: 81 passed. Browser checks for dismissal, ordered drops, drag-versus-pan separation, contrast and linked preloading also passed.

The uncapped suite then reached 3,900 passes with three additional failures. Two exposed real Snapshot/Quick Import forwarding drift: photo-stage listing and photo copying rejected the exact `job_path` argument. Four new forwarding tests reproduced the TypeError before fixing both proxies to forward all arguments. The third assertion was updated to follow the preload-aware fast-read call. All 17 parity/performance tests now pass. A final full run and rebuild are in progress; earlier installer hash below is superseded by this source fix.
